# Changelog

## 2.1.0 - 2026-09-07

### MQTT identity / Gladys
- Changed per-button MQTT topics to stable Flic serial-number identity.
- Status is retained on `flic/<SERIAL>/status`.
- Events are non-retained on `flic/<SERIAL>/event`.
- Removed slot-number per-button publishing and separate retained `battery_mv` / `battery_pct` scalar topics.
- Battery, connection, firmware and other feature values remain in the retained status JSON for Gladys JSON-path extraction.
- Retained status is tombstoned by serial number when a Flic is deleted/unpaired.

### Build cleanup
- Removed ESP-IDF/NimBLE command-line definitions that were redefined by ESP32-C6's generated NimBLE configuration.
- Removed unnecessary `volatile` from the database generation counter, eliminating the modern C++ volatile increment warning.
- Documentation now reflects the required Huge APP menu selection used to satisfy Arduino's size checker while the local `partitions.csv` supplies the real dual-OTA layout.
- Documented fixed-port ArduinoOTA/firewalld setup tested with callback TCP port 3233.

## 2.0.0 - 2026-09-07

### Reliability
- Replaced `millis()` Flic steady clock with 64-bit `esp_timer_get_time()`.
- Corrected stored pairing detection to inspect the first four pairing bytes.
- Added temporary-slot reservation and cleanup for new-button pairing.
- Reset reconnect backoff after successful pairing/reauthentication.
- Drain events generated by `flic2_on_disconnected()`.
- Pass the actually negotiated MTU to `flic2_start()` and removed duplicate MTU exchange.

### BLE architecture
- Replaced permanent per-button NimBLE ownership with a fixed pool of 3 reusable clients.
- Prefer reuse of the same client's cached peer attributes when possible.
- Never call `NimBLEDevice::deleteClient()` at runtime.

### Observability
- Added queued MQTT remote logs on `flic/bridge/log`.
- Added retained health metrics on `flic/bridge/metrics`.
- Added battery percentage to per-button JSON status.

### OTA / flash
- Added ArduinoOTA network upload support.
- Added a custom 4 MiB dual-OTA `partitions.csv` with 1,966,080 bytes per application slot.

### Maintenance / security
- Moved the implementation into `bridge_app.cpp` to avoid Arduino `.ino` auto-prototype problems.
- Moved credentials into git-ignored `secrets.h` and added `secrets.example.h`.
- Removed pairing-key output from diagnostics.
